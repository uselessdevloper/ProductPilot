# OptAgent: Query Rewriting and Automated Attribute Label Optimization for Industrial Search Indexing

**Authors**: Etsy Search & Machine Learning Team  
**Category**: Agentic Commerce & Autonomous Systems Research  
**Paper Reference ID**: AGY-RES-2026-08  

## Abstract

We develop an automated query rewriting engine that transforms conversational AI buyer search intents into canonical e-commerce search vectors and facet filters.

## 1. Parametric Query Translation

Converts natural language procurement requests into structured SQL / Vector query filters, boosting product match rates by +25.2%.
