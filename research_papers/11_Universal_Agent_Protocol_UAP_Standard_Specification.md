# Universal Agent Protocol (UAP): Architectural Standards for Autonomous Discovery, Price Bounding, and Payment Handshakes

**Authors**: Open Agentic Commerce Working Group  
**Category**: Agentic Commerce & Autonomous Systems Research  
**Paper Reference ID**: AGY-RES-2026-11  

## Abstract

The official architectural specification of the Universal Agent Protocol (UAP-2026), defining JSON-LD schemas, intent parsing, price envelope negotiation, and HMAC-signed settlement handshakes with payment gateways.

## 1. Protocol Architecture & Handshake Specification

Defines the 4-phase transaction lifecycle: Discovery -> Price Envelope Negotiation -> Cryptographic Verification -> Programmatic Settlement via Razorpay.
